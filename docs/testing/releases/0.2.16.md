## Release decision

- Automated checks: Rust API, CLI, common, service, and xTool tests passed. Focused frontend controller tests, the production frontend build, formatting, and adapter-specific linting passed.
- Known failures: the strict repository-wide Clippy run reports existing warnings in unrelated core files; adapter-specific Clippy passed with dependency linting disabled.
- Checks not run and why: physical laser behavior, original xTool M1 hardware, manual installed-candidate checks, updater validation, and package inspection were unavailable before signed packaging.
- Decision: proceed with signed platform builds. The new controller remains explicitly Experimental until original M1 owners report physical test results.
