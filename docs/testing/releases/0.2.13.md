## Release decision

- Automated checks: full Rust workspace tests, frontend tests, lint, production build, formatting, and Clippy passed.
- Known failures: none in automated validation.
- Checks not run and why: physical laser behavior and manual installed-candidate checks were unavailable before release packaging.
- Decision: proceed with signed platform builds. This release opens the existing Experimental Ruida Ethernet runtime to RDC6445G and other responding variants while preserving acknowledged transfer, lifecycle, cleanup, and stop safeguards. Physical compatibility remains unverified until controller owners report results.
